RONAQ ERP — حزمة المصدر 0.22.4 (تحديث واجهة سجل المبيعات وملف المحاسب)

التحديثات في هذه الحزمة:
1) جعل زر «المحاسب» قابلاً للضغط وفتح قائمة ملف المحاسب مع اختصار إلى إعدادات النظام.
2) إضافة سجل المبيعات: اختيار تاريخ يعرض قوائم ذلك اليوم، وترك التاريخ فارغاً يعرض جميع القوائم.
3) إبقاء قوائم اليوم في لوحة جانبية مستقلة أثناء استعراض سجل المبيعات.
4) تحديث رقم الإصدار الظاهر في تذييل التطبيق إلى 0.22.4.

ملاحظات التحقق:
- اجتازت اختبارات smoke المتعلقة بإعادة تشغيل التطبيق بعد التصفير، وسجل الفواتير والطباعة، ومدفوعات المبيعات، وتفاصيل مبيعات السائقين، وواجهات التقارير والمرتجعات، وأصول بناء Windows.
- اجتاز فحص ثابت وجود عناصر زر المحاسب وسجل المبيعات وفلتر التاريخ وقائمة اليوم الجانبية.
- لم يتم تنفيذ بناء TypeScript/Electron أو إنتاج Setup.exe في بيئة إعداد هذه الحزمة؛ يجب تنفيذ npm install ثم npm run typecheck ثم npm run dist:win على Windows.
- هذه حزمة مصدر وليست مثبتاً جاهزاً. لا تعتمدها في تشغيل المصنع قبل اختبار المثبت وقاعدة البيانات والنسخ الاحتياطي على جهاز منفصل.
